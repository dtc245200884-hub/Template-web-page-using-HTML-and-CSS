Web Technology

HTML (HyperText Markup Language) la ngon ngu danh dau duoc su dung de xay dung cau truc trang web. HTML cho phep trinh duyet hien thi van ban, hinh anh, lien ket va cac thanh phan noi dung. Ket hop HTML voi CSS va JavaScript giup tao ra nhung trang web hien dai, truc quan va co tinh tuong tac.

C Programming

C la ngon ngu lap trinh thu tuc duoc phat trien boi Dennis Ritchie. Ngon ngu C co toc do xu ly nhanh, kha nang truy cap bo nho cap thap va duoc su dung trong phat trien he dieu hanh, trinh bien dich, he thong nhung va nhieu ung dung khac.

Java Programming

Java la ngon ngu lap trinh huong doi tuong pho bien. Ma nguon Java duoc bien dich thanh bytecode va chay tren Java Virtual Machine (JVM), giup chuong trinh co the hoat dong tren nhieu nen tang. Java duoc su dung trong phat trien web, ung dung doanh nghiep va Android.
